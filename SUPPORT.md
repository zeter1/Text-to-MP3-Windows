# Поддержка и диагностика

Если проблема воспроизводится на текущей версии Text to MP3, создайте GitHub Issue через форму **Сообщить об ошибке**.

## Что указать

- commit/версию приложения;
- Windows 10/11 и версию Python;
- используемый SAPI-голос;
- связано ли поведение с чтением, hotkey, MP3-конвертацией, recovery или аудиоустройством;
- точные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- небольшой релевантный фрагмент из `Логи проблем/`.

Если ошибка связана с MP3, также полезно указать, найден ли FFmpeg через `imageio-ffmpeg` или системный `PATH`.

## Данные пользователя

Программа хранит runtime/recovery данные в каталогах `Настройки программы/`, `Логи проблем/`, `Незавершённые задачи/` и `Бэкапы текста MP3/`. Эти каталоги исключены из Git, но перед публикацией файлов всё равно проверьте, что в них нет личного текста или путей, которыми вы не хотите делиться.

## Быстрая проверка репозитория

```powershell
python -m compileall -q text_to_mp3.py tests
python -m unittest discover -s tests -v
```

Эти проверки не подтверждают реальную работу Microsoft SAPI, COM, аудиоустройства, глобальных hotkeys или FFmpeg-кодирования. Такие сценарии требуют runtime-проверки в Windows.
