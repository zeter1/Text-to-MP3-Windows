# ZeTer Voice

**ZeTer Voice** — desktop-приложение на Python для озвучивания текста голосами Windows SAPI, локальными Silero и онлайн Microsoft Edge и сохранения текста в MP3. Программа поддерживает несколько вкладок, глобальные горячие клавиши, восстановление прерванных заданий и работу с длинными текстами.

Проект рассчитан на повседневное использование: можно слушать текст прямо в приложении, захватывать выделенный текст из других программ и создавать аудиоверсии статей, заметок и документов.

## Скачать и запустить на Windows

> Windows-сборки помечены **Prerelease**: это предварительные версии для тестирования. Сборка в Releases может отличаться от текущих исходников.

Готовая программа позволяет слушать текст и сохранять его в MP3 системными голосами Windows.

1. Откройте [GitHub Releases](https://github.com/zeter1/ZeTer-Voice/releases) и разверните **Assets** у выбранной сборки.
2. Скачайте `ZeTer-Voice-x64.zip` (в прежних релизах — `Text-to-MP3-Windows-x64.zip`) и распакуйте архив целиком.
3. Запустите `ZeTer-Voice.exe` (в прежних релизах — `Text-to-MP3-Windows.exe`) из распакованной папки, вставьте текст и выберите голос.

Python, `pywin32` и FFmpeg входят в готовый дистрибутив. Сохраняйте рядом с EXE папку `runtime`. Для озвучивания в Windows должен быть установлен хотя бы один **Microsoft SAPI voice**. Рядом с ZIP опубликован файл SHA-256.

## Что демонстрирует проект

- интеграцию Python с Microsoft SAPI и COM через `pywin32`;
- работу с глобальными Windows hotkeys и передачей выделенного текста между приложениями;
- управление состоянием нескольких независимых вкладок;
- длительную генерацию MP3 с данными восстановления после прерывания;
- интеграцию синтеза речи с FFmpeg;
- хранение локального пользовательского состояния и отделение runtime-данных от репозитория;
- лёгкую CI-проверку Windows-зависимого проекта без попытки эмулировать SAPI и аудиоустройства.

## Русские голоса и управление движками


Вверху окна есть вкладки **«Озвучивание»** и **«Голосовые движки»**. Во второй можно установить Silero или Edge, увидеть их состояние и удалить выбранный движок с подтверждением. Уже существующие компоненты при установке пропускаются. Удаление переносит только модель Silero или отдельную копию Edge в резервную папку; Windows SAPI, другие системные голоса, тексты и настройки сохраняются. Во время прослушивания или создания MP3 управление движками заблокировано.

- **Silero — без интернета:** Ксения, Ксения (вариант 2), Бая, Айдар, Евгений. После первоначальной установки модель работает локально, без отправки текста в сеть. Видеокарта не требуется.
- **Microsoft Edge — интернет:** Светлана и Дмитрий. При выборе такого голоса текст передаётся Microsoft для озвучивания. Автоматического переключения с локального движка на онлайн нет.
- **Windows SAPI:** прежние системные и сторонние совместимые голоса остаются в том же списке.

При первом запуске из исходников нужны Python для Windows, `pywin32` и FFmpeg (допустим пакет `imageio-ffmpeg`). Дополнительные движки используют PyTorch и Edge TTS. Подготовка из папки программы:

```powershell
python tools/setup_voices.py --install-deps
```

Команда скачивает проверяемую модель Silero (около 148 МБ) и при необходимости библиотеки. Для Edge используется отдельная копия версии 7.3.1 внутри `Движки речи`, чтобы не обновлять Edge TTS других программ. Если модель и библиотеки уже подготовлены, повторная установка не нужна. Офлайн-озвучка не скачивает модель автоматически.

Запустите программу, вставьте короткий текст, выберите в поле «Голос» вариант `Silero … (без интернета)` и нажмите кнопку прослушивания либо создания MP3. Первый запуск Silero может занять несколько секунд. Для новых движков закладка и выделение при прослушивании идут по предложениям; скорость, тон и громкость применяются при подготовке звука, поэтому изменение требует повторного запуска чтения.

Настройки, вкладки, резервные копии текста и незавершённые задачи хранятся в прежних папках рядом с программой. Подробности установки, условий моделей и диагностики — [docs/VOICE_ENGINES.md](docs/VOICE_ENGINES.md).

## Установка из исходников

1. Установите Python 3.13 для Windows — на этой версии проверены программа и дополнительные движки.
2. Убедитесь, что в Windows установлен хотя бы один голос Microsoft SAPI.
3. Скачайте проект через **Code → Download ZIP** либо Git:

```bash
git clone https://github.com/zeter1/ZeTer-Voice.git
cd ZeTer-Voice
```

4. Создайте виртуальное окружение и установите зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

Для MP3 используется `imageio-ffmpeg` либо FFmpeg из системного `PATH`.

## Запуск из исходников

```powershell
py text_to_mp3.py
```

## Как пользоваться

### Озвучивание текста

1. Запустите программу.
2. Вставьте или напечатайте текст во вкладке.
3. Выберите голос, скорость, громкость и другие параметры.
4. Нажмите кнопку чтения.
5. Используйте паузу и продолжение, если нужно временно остановить озвучивание.

### Захват текста из другой программы

1. Настройте глобальную горячую клавишу для нужной вкладки.
2. Выделите текст в браузере, документе или другом приложении.
3. Нажмите назначенную горячую клавишу.
4. Выделенный текст будет передан в ZeTer Voice для дальнейшего чтения или сохранения.

### Создание MP3

1. Подготовьте текст во вкладке.
2. Выберите голос и настройки синтеза.
3. Укажите параметры MP3.
4. Запустите сохранение.
5. Для длинных заданий программа сохраняет данные восстановления, чтобы не начинать весь процесс заново после части сбоев.

## Архитектура

`text_to_mp3.py` — компактная точка входа. Реализация разделена на модули в `tts_app/`; владельцы подсистем и постоянных данных описаны в [обзоре проекта](docs/PROJECT.md) и [карте кода](docs/CODEMAP.md):

```text
Tkinter UI / tabs
    ↓
text state + settings
    ↓
Microsoft SAPI / COM speech
    ↓
audio playback / MP3 pipeline
    ↓
FFmpeg
    ↓
recovery + backups + diagnostics
```

Отдельные модули отвечают за Windows hotkeys, перенос выделенного текста, автозапуск и сохранение состояния. Совместимые фасады сохраняют прежние точки импорта.

## Для чего подходит

- прослушивание длинных текстов вместо чтения с экрана;
- подготовка аудиоверсий статей и заметок;
- создание MP3 из текста;
- быстрый голосовой просмотр выделенного текста;
- работа с несколькими текстами одновременно.

- `pywin32` — Microsoft SAPI, COM и Windows-интеграция;

Большая часть остальной логики использует стандартную библиотеку Python.

## Проверка проекта

```powershell
python -m unittest discover -s tests -v
python tools/verify.py
```

Локальный `tools/verify.py` запускают в отдельной копии исходников без пользовательских данных: [правила изоляции](docs/LOGGING_FOR_AI.md). GitHub Actions проверяет repository contracts, импорты, preview/hotkey regression tests и логи в чистом checkout. Для коммитов `[package]` дополнительно выполняются Windows-сборка и packaged SAPI/FFmpeg self-test.

## Ограничения и уровень проверки

- приложение предназначено только для Windows 10/11;
- реальная работа SAPI, COM, глобальных hotkeys и аудиоустройств требует runtime-проверки Windows;
- MP3 pipeline зависит от доступного FFmpeg;
- качество и набор голосов зависят от установленных SAPI voices;
- CI не утверждает, что аппаратно- и Windows-зависимые сценарии полностью проверены.

Программа предназначена для Windows 10/11, поскольку использует Microsoft SAPI, COM, Win32 API и системные функции Windows.
