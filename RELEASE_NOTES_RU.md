# Text to MP3 для Windows — 4.2.4 FULL (исправления от 26 октября 2026)

Сборка из обновлённых исходников в ветке `main`. Номер версии приложения остаётся **4.2.4 FULL**; в релиз включены дополнительные исправления от 26 октября.

## Исправления в этой сборке

- Устранена ложная ошибка остановки Windows SAPI после уже подтверждённого завершения чтения: для успешно озвученного текста больше не выполняется лишний purge. При Stop и ошибках принудительное завершение сохранено.
- При ошибках аудиовывода SAPI `0x80045006`–`0x80045009` отображается код и рекомендация. При проблеме аудиодрайвера или неподтверждённом воспроизведении непрочитанный текст не считается озвученным и не удаляется.
- Улучшено копирование текста из Telegram и других программ: при временной занятости буфера обмена выполняются до четырёх коротких неблокирующих повторных попыток. Проверка номера последовательности защищает от захвата текста следующего копирования.
- В журналы добавлены сведения о повторных попытках чтения буфера и этапах освобождения SAPI; пользовательский текст в эти события не записывается.
- Добавлены регрессионные тесты работы с Bluetooth-подобными ошибками, отказом драйвера, остановкой чтения и блокировкой clipboard.

## Что было улучшено ранее в 4.2.4

- Обработка длинных строк и восстановление переноса по мере уменьшения текста без изменений сохранённого содержимого.
- Watchdog интерфейса и диагностические отчёты о зависаниях, обработка ошибок Tk и фоновых потоков.
- Защита от одновременного запуска нескольких экземпляров программы.

## Установка

Скачайте `Text-to-MP3-Windows-x64.zip` из блока **Assets**, полностью распакуйте архив в отдельную папку и запустите `Text-to-MP3-Windows.exe`. Отдельная установка Python и FFmpeg не требуется. Озвучивание использует установленные в Windows голоса Microsoft SAPI и доступные драйверы звука.

## Проверки и ограничения

Для исправленных исходников локальный `python tools/verify.py` прошёл успешно (23 регрессионных теста воспроизведения и горячих клавиш). Итоги упаковки и автоматических тестов конкретного EXE смотрите в GitHub Actions соответствующего коммита.

Продолжительная работа с физическими Bluetooth-наушниками после правок и единичное зависание Tk из старых журналов отдельно не подтверждены. Если Windows сообщает `0x80045009`, переподключите устройство и проверьте его драйвер: программа не может восстановить неисправный системный аудиодрайвер.

Настройки, пользовательские тексты и журналы ошибок в архив не включаются.
