# Новая версия: постоянные уведомления о готовых MP3

- Каждая успешно завершённая конвертация теперь показывает отдельное постоянное уведомление поверх окон справа внизу рабочего стола. Уведомления не исчезают по таймеру, работают независимо и сохраняются при сворачивании главного окна.
- Вместо блокирующего диалога «ОК» показываются имя файла, папка и кнопка «Показать файл». Кнопка открывает Проводник с выделенным MP3, не закрывая уведомление.
- Уведомления можно закрывать по одному крестиком. Если готового файла больше нет, программа открывает существующую папку или показывает ошибку, не создавая новых каталогов.
- Добавлены regression tests и проверка запуска на главном Tk-потоке. Сохранены изменения предыдущего релиза: защита чтения через SAPI и фильтрация захвата пунктуации.

## Скачать и запустить

Скачайте и распакуйте весь `Text-to-MP3-Windows-x64.zip`, затем запустите `Text-to-MP3-Windows.exe`. Папку `runtime` нельзя отделять от исполняемого файла. Python, pywin32 и FFmpeg отдельно устанавливать не нужно. Используются доступные системные голоса Microsoft SAPI.

Архив сопровождается файлом SHA-256. Тег `build-<commit>` указывает на точные исходники релиза.

## Проверки и ограничения

Изолированные тесты Python прошли на исходниках. Перед публикацией GitHub Actions должен выполнить Windows regression gate, создать ONEDIR-дистрибутив и провести packaged self-test SAPI/COM и FFmpeg. Реальные клики в пользовательском интерфейсе, использование нескольких мониторов, фактическая MP3-конвертация и длительная работа аудиоустройства остаются предметом отдельной проверки на Windows.
