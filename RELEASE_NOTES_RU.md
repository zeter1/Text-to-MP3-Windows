# Изменения Windows-сборки

- Исходники обновлены до самой свежей модульной версии из пользовательского архива.
- Большой монолитный `text_to_mp3.py` заменён компактной точкой входа; рабочая реализация теперь находится в модулях `tts_app/*`.
- Сохранены функции преобразования текста в MP3, Microsoft SAPI, горячие клавиши, восстановление задач, диагностика и логирование.
- CI дополнительно компилирует весь пакет `tts_app`, чтобы синтаксические ошибки в новых модулях не проходили незамеченными.
- Готовая Windows-сборка публикуется как portable ZIP с `Text-to-MP3-Windows.exe`, папкой `runtime` и отдельным SHA-256.

## Проверка

Перед публикацией CI выполняет compile, offline regression tests, проверку SAPI/FFmpeg contracts, сборку EXE и packaged startup/self-test на GitHub-hosted Windows runner.

Реальное воспроизведение через пользовательские SAPI-голоса, аудиоустройства и длительная MP3-конвертация требуют дополнительной runtime-проверки на целевой Windows-машине.
