## Исправлено
1. Очередь событий Tk обрабатывается короткими пакетами: максимум 80 за callback и ориентировочно 10 мс после первых 8 событий. При очереди новый проход ставится через 1 мс, а не через 100 мс.
2. Если опрос Windows SAPI завершился ошибкой, при конкретном выбранном устройстве теперь начинается повторная проверка через 12 секунд, даже когда прежний статус missing ещё не устанавливался. Для системного устройства повторяется сам опрос. При новом выборе отменяется устаревшая проверка.
3. Для F8/пользовательских сочетаний после обычного окна ожидания и grace period возможна одна дополнительная попытка Ctrl+C. Она производится только если активное окно имеет исходные HWND и PID. Обычный Ctrl+C не переотправляется, устаревшая generation не захватывается.
4. Массовые последовательные добавления текста больше не запускают синхронный сброс всего workspace на диск при каждом захвате; используется отложенное сохранение с первым сроком до 500 мс. При штатном закрытии исходный код вызывает немедленное сохранение. Python-индексы символов оставлены без замены на Tk.count, так как Tk 8.6 и Python считают emoji по-разному.
5. Устаревший runtime_core.cpython-313.pyc кодировал `4.2.3 FULL`, хотя исходник и файл размер/mtime соответствовали `4.2.4 FULL`. При публикации удаляются только генерируемые *.pyc из кэшей данного проекта. Это обеспечивает новую компиляцию из актуальных исходников.

## Границы
- Ошибку устройства Windows SAPI `AUDIO_OUTPUT_NOT_FOUND` и отказ wave-драйвера `0x80045009` нельзя устранить только логикой приложения, пока устройства недоступны ОС.
- Исходное зависание Tk, зафиксированное в `Tk.mainloop()`, не имеет доказанной единственной причины. Ограничение очереди и сохранения снижает риск, но не доказывает исчезновение всех зависаний.
- Сохранение по debounce предполагает окно до 500 мс при внезапной гибели процесса. Штатный выход делает немедленный flush.
- Проверки в изолированной копии не доказывают реальную слышимость на Bluetooth, работу F8 в Telegram после длительного использования, работу упакованного EXE и многодневную стабильность.
