# Движки русской речи

## Выбор и установка

Верхняя вкладка «Голосовые движки» управляется `engine_manager_ui.py`. Старая рабочая тетрадь с текстовыми вкладками остаётся внутри «Озвучивание»; её порядок, индексы и формат workspace не меняются.

Для каждого из двух дополнительных движков доступны «Установить» и «Удалить», состояние и отмена фоновой операции. Установка не заменяет существующий файл/каталог. Недостающие библиотеки устанавливаются в staged `--target` внутри программы, не в общий Python; PyTorch из общей среды имеет приоритет перед локальным fallback. Windows SAPI и сторонние голоса не являются управляемыми целями.

Удаление требует отдельного подтверждения и недоступно при активном чтении/конвертации. Оно выполняет один rename только фиксированного пути модели или частной библиотеки в `_maintenance_backups/removed_engines/<движок>_<id>`. Сохранённая копия позволяет вручную восстановить движок; повторная установка скачивает новую копию. Общие зависимости и пользовательские данные не удаляются. После удаления Edge worker не использует старую глобальную библиотеку как скрытую замену.

`engine_installation.py` владеет точными путями, staged install и восстановимым удалением; `tools/manage_voice_engine.py` запускается отдельным процессом без импорта приложения. Tk получает результаты через очередь; отмена закрывает принадлежащее операции дерево процессов. При отмене уже опубликованные компоненты сохраняются, временная staging-папка может остаться до ручной уборки. Программа не удаляет её автоматически.

В списке «Голос» доступны прежние Windows SAPI и дополнительные варианты:

| Название | ID | Обработка |
|---|---|---|
| Silero — Ксения | kseniya | Локально |
| Silero — Ксения, вариант 2 | xenia | Локально |
| Silero — Бая | baya | Локально |
| Silero — Айдар | aidar | Локально |
| Silero — Евгений | eugene | Локально |
| Microsoft Edge — Светлана | ru-RU-SvetlanaNeural | Онлайн, текст передаётся Microsoft |
| Microsoft Edge — Дмитрий | ru-RU-DmitryNeural | Онлайн, текст передаётся Microsoft |

Локальная модель — Silero `v5_6_ru`, CPU, 24 кГц. Работает без интернета после установки; автоматической загрузки и облачного fallback при чтении нет. Модель должна находиться в `Движки речи/silero_v5_6_ru.pt` относительно исходников. При ошибке hash она не загружается. Голоса добавлены к существующему строковому полю настроек без изменения схемы workspace/recovery.

Подготовить из корня программы:

```powershell
python tools/setup_voices.py --install-deps
```

Если библиотеки уже есть, только загрузить модель: `python tools/setup_voices.py`. Установить заранее скачанный файл: `python tools/setup_voices.py --model-file "путь к модели.pt"`. Во всех случаях требуется фиксированный SHA256 из `tts_app/voice_catalog.py`. Загрузка идёт с официального HTTPS-адреса с проверкой размера/hash; существующая исправная модель сохраняется. Перед заменой повреждённого файла создаётся копия `silero_previous_<hash>.pt`.

Для личного некоммерческого применения доступны русские модели Silero; условия модели задаёт [официальный проект](https://github.com/snakers4/silero-models#licence), не лицензия Python-кода этой программы. Модель является исполняемым PyTorch package: использовать только закреплённый артефакт официального источника. Hash фиксирует выбранный артефакт и не является независимым аудитом его кода.

Edge TTS — сторонняя библиотека доступа к онлайн-сервису Microsoft. Установка держит версию 7.3.1 отдельно в `Движки речи/edge_tts_7_3_1`; остальные приложения используют прежние библиотеки. Доступность сервиса зависит от сети и изменений Microsoft. При ошибке выберите Silero; текст автоматически в другой сервис не отправляется. Справка: [Edge TTS](https://github.com/rany2/edge-tts).

## Владельцы и контракты

- `voice_catalog.py`: точная таблица голосов, путь и hash модели, чтение одного проверенного file handle.
- `voice_worker.py`: отдельный Python-процесс, ленивые импорты PyTorch/Edge, синтез CPU; исключения сервиса заменяются фиксированными кодами без текста и ответов сервера.
- `voice_process.py`: жизненный цикл worker, ограниченный JSONL через stdin/stdout, асинхронная запись в pipe, timeout/cancel/reap; FFmpeg нормализует PCM и применяет скорость/тон/громкость. WAV публикуется после проверки, временные файлы принадлежат одному вызову.
- `generated_preview.py`: предложения с точными исходными offsets, WAV через SAPI `SpeakStream` на выбранном устройстве. Только завершённое воспроизведение с положительным audio delta допускает callback `playback_verified`. Создание WAV само по себе прочтение не подтверждает.
- `task_conversion_worker.py`: один сеанс на MP3-задачу, прежние WAV checkpoints, финальная проверка MP3 и восстановление. Для новых движков нет автоматических повторов неясной ошибки и сохранения текста фрагмента в диагностический error bundle. Recovery/source backup сохраняет текст по прежнему контракту.

Новые движки доступны из исходников и в переносимой Windows-сборке ZeTer Voice. Отдельный `engine_runtime/python.exe` со стандартной библиотекой и pip подготавливается из чистого build Python 3.13 без системных site-packages. Внешние worker/installer находятся в соседних `tts_app` и `tools`: переносите весь дистрибутив. Модель Silero и библиотеки дополнительных движков загружаются явно через вкладку управления и не входят в архив по умолчанию. Настройки, исходный текст, старые MP3 и recovery установка движков не переносит и не удаляет.

## Проверки

`python tools/verify.py` в source mirror включает `tools/test_extra_voices.py`: порядок офлайн/онлайн, недоверенная/отсутствующая модель, timeout и Stop, заблокированная stdin-запись, приватность ошибки, повреждённый WAV, подтверждение playback и сохранение первичной ошибки при сбое cleanup.

Для native проверки используйте короткий искусственный текст: Silero → прослушивание → пауза → остановка → повторный запуск; затем MP3. Непрочитанное предложение должно оставаться. Отдельно проверьте выбранные наушники и Edge при наличии сети. Синтетические COM-тесты не доказывают физический звук или Bluetooth.
